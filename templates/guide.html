Nmap (Network)
Network Recon & Port Scanning
Maps the attack surface by finding open ports and services.
nmap -sT -Pn -v 192.168.0.77
nmap -sT -sV -Pn -v -A 192.168.0.77
nmap --script vuln -sT -sV -Pn 192.168.0.77
nmap -sU -Pn 192.168.0.77
SQLMap (Web)
SQL Injection
Automated detection and exploitation of SQL injection flaws.
python C:\\Tools\\sqlmap\sqlmap.py -u "http://target.com/page?id=1" --batch
python C:\\Tools\\sqlmap\sqlmap.py -u "http://target.com/login" --forms --crawl=2 --batch
python C:\\Tools\\sqlmap\sqlmap.py -u "http://target.com/login" --data="user=test&pass=test" -p "user" --batch
Dalfox (Web)
Cross-Site Scripting (XSS)
Fast XSS scanner that supports GET and POST parameters.
dalfox url "http://target.com/search?q=test" --silence
dalfox url "http://target.com/login" --method POST --data "user=test&pass=test" --silence
Nuclei (Web/Network)
Template-Based Vulnerability Scanning
Checks for known CVEs, misconfigurations, and exposures.
nuclei -u "http://target.com" -tags cve -silent
nuclei -u "http://target.com" -tags exposure,misconfig -silent
nuclei -u "http://target.com" -dast -silent
WhatWeb (Web)
Technology Fingerprinting
Identifies CMS, server versions, and frameworks. Note the Ruby prefix.
ruby C:\\Tools\\WhatWeb\\whatweb "http://target.com" --color=never
ruby C:\\Tools\\WhatWeb\\whatweb "http://target.com" --aggression=3 --color=never
DNSenum (Network)
DNS Enumeration
Finds subdomains and DNS records for a target domain.
perl C:\\Tools\\dnsenum\dnsenum.pl target.com --threads 5
